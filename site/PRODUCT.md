# Revora landing page

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

Explain Revora, an open-source Windows recovery-mode and IPSW firmware utility for iPhone and iPad. Provide access to the repository and prereleases. Product facts come from the repository README; the audience of people evaluating the utility is inferred from this page's purpose.

## Capabilities and Constraints

Windows 10/11 x64; .NET Framework 4.8; Apple USB drivers required. Device details, normal/recovery/DFU recognition, recovery controls, local IPSW compatibility checks, and update/erase workflows. Real-device recovery and restore require validation. Updates cannot guarantee data preservation; erase deletes data. No hardware repair or Activation Lock bypass. Apple firmware signing restrictions still apply.

## Brand Commitments

Preserve Revora's name, existing circle-and-wave logo, and blue emphasis. The user requested a distinctive landing page followed by polish. The desktop app stays independent.

## Evidence on Hand

Repository README and device-validation guide. Three existing UI-test screenshots with synthetic device data. No testimonials, performance claims, or device-validation results are supplied.

## Stack

Static HTML, CSS, and JavaScript, selected for a standalone page with no runtime dependencies. Deployment is not configured by this change.
